# STEP RULES: PRIMARY MAIL (sequence_step 1)

This is the first mail. Day 0. It makes one observation and states the offer.

- Length: under 80 words. Aim for under 65.
- Subject: 2 to 5 words, all lowercase, plain and curious. No question mark. No company name in caps.
- Structure, in this order:
  1. One observation line about the lead. Use trigger (if verified), personalization_note, or a fact from "extra".
  2. One problem the lead likely has, in the buyer's words (SENDER problem_solved).
  3. One call to action.
  4. The sender first name.
- Call to action: a soft permission question is allowed, for example "Worth a short look?". Use low_friction_offer if it is not empty.
- Offer: say what the sender does in one sentence (SENDER offer). Name the outcome only as SENDER outcome states it.
- No links. No attachments. No question about the lead's time.
- angle_used: name the angle of this mail, for example "trigger: new hire in sales".
